<p align="center">
  <b>Automate client onboarding with AI-powered email responses</b>
</p>

---

## ✨ Overview
This project automates the client onboarding process using an AI agent.  
When a client submits a form, the system instantly generates and sends:

- ✉️ **Welcome Email** – Personalized greeting  
- 📄 **Terms & Conditions Email** – Service details & policies  

⚡ Fast • 🤖 Smart • 🔁 Fully Automated

---

## 🧠 How It Works
1. Client fills out form  
2. Data is captured in workflow  
3. AI generates email content  
4. Emails are sent automatically

## ⚙️ Setup Guide
1. Import `workflow.json` into n8n  
2. Connect Gmail account  
3. Add AI API key  
4. Run workflow  
5. Submit form → Emails sent automatically
